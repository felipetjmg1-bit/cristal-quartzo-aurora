# CRISTAL DE QUARTZO AURORA · fluxo passo a passo

API demonstrativa para ingestão, recuperação e status.

## 1. ENVIAR DADO DE TESTE

Preparar payload sintético sem informação sensível.

## 2. VALIDAR REQUISIÇÃO

Enviar o payload à API FastAPI para validação.

## 3. SIMULAR INGESTÃO

Executar o fluxo de armazenamento demonstrativo.

## 4. CONSULTAR STATUS

Consultar o estado e os metadados registrados.

## 5. RECUPERAR RESULTADO

Verificar a resposta e as limitações do armazenamento simulado.

## Resultado e limites

API de simulação. Não comprova armazenamento físico em cristal nem capacidade quântica.
